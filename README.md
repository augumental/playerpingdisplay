# Player Ping Display 1.2.0 — Fabric jars

Each Minecraft version has its own installable jar. Use Fabric Loader 0.19.3 or newer and the Fabric API for that version. Java 21 is required for 1.21.x; Java 25 for 26.x.

Press U in-game to open settings. Reset the binding in Controls if an older installation still has it unbound. Click and drag the preview in settings to move the HUD. All customization options are included.

Replace your older Player Ping Display jar with the one matching your Minecraft version. Install one jar at a time.
